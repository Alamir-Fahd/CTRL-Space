# User guide

**Ask.** Type a question about flame spread, extinction, oxygen, airflow or combustion products. You get a short answer and numbered points; each point has citation chips showing the NTRS ID and page, slide or section. Click a chip to read the exact passage. If the evidence isn't strong enough, CTRL+SPACE says so instead of guessing. Without an AI provider configured, you see the matching evidence only.

**Library.** Search titles, authors and passage text, filter by program, sort by date or title. Open a report to see its metadata, its verified passages, links to the NTRS record and original PDF, and the experiments taken from it. Signed-in users can keep private notes.

**Experiments and Compare.** Each experiment lists ten fields. Grey italic text means the value is not in the verified text (*Not reported*) or hasn't been taken from it yet (*Not extracted*). Tick 2 to 4 experiments and open Compare. Read the yellow warning box before drawing conclusions: different programs, hardware or flow directions make results hard to compare. Charts appear only for fields with a single number in the same unit.

**Collections.** Create an account, then use *Add to collection* on any report or experiment. Export a collection as Markdown with sources and your notes.

**Admin.** Import a report by NTRS ID, review each extracted passage against the original page (choose its type, then Verify or Reject), approve the report, and check the audit log.
